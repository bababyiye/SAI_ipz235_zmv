\# AI Game Master — Локальний текстовий RPG-квест (Python + Tkinter + Ollama)



Інтерактивна текстова RPG-гра, де локальна мовна модель (`qwen3.5:9b`) виступає ведучим (Game Master): генерує сюжет у реальному часі (стрімінгом), відстежує здоров'я (`HP`), золото та інвентар персонажа, формує 3 швидкі варіанти дій і реагує на довільні команди гравця.



\## Структура теки `app/`



\- `main.py` — вихідний код десктопного застосунку на Python (`tkinter` + `openai`).

\- `build\_exe.bat` — скрипт автоматичної збірки автономного виконуваного файлу `AI\_Game\_Master.exe`.

\- `run.bat` — швидкий запуск програми у Windows подвійним кліком без консольного вікна.

\- `README.md` — інструкція зі встановлення, запуску та опис параметрів генерації.



\## Підготовка локального сервера моделей



1\. Встановіть \*\*Ollama\*\* для Windows: https://ollama.com/download

2\. Завантажте локальну модель `qwen3.5:9b`:

&#x20;  ```bash

&#x20;  ollama pull qwen3.5:9b

&#x20;  ```

3\. Переконайтеся, що сервер Ollama запущений (`http://localhost:11434/v1`). Якщо він не працює у фоні, запустіть у терміналі:

&#x20;  ```bash

&#x20;  ollama serve

&#x20;  ```



\## Способи запуску застосунку



\### Варіант 1. Запуск через `.exe` файл (найзручніший)

1\. Запустіть \*\*`build\_exe.bat`\*\* (потрібен встановлений Python 3.10+ та доступ до `pip` лише під час першої збірки).

2\. Після завершення в теці з'явиться файл \*\*`AI\_Game\_Master.exe`\*\*.

3\. Запускайте гру подвійним кліком по \*\*`AI\_Game\_Master.exe`\*\* (Python для подальших запусків уже не потрібен).



\### Варіант 2. Швидкий запуск через `run.bat`

\- Двічі клікніть \*\*`run.bat`\*\* — скрипт автоматично перевірить наявність бібліотеки `openai` і запустить вікно гри через `pythonw.exe`.



\### Варіант 3. Запуск із терміналу напряму через Python

```bash

pip install openai

python main.py

```



\## Обґрунтування параметрів генерації



\- \*\*`temperature = 0.7`\*\*: оптимальний баланс між творчою різноманітністю сюжетних описів та стабільним дотриманням формату службового рядка стану `\[STATE: HP=... | GOLD=... | INV=... | OPT1=... | OPT2=... | OPT3=...]`.

\- \*\*`max\_tokens = 450`\*\*: обов'язковий ліміт вихідних токенів на один хід. Запобігає зацикленню моделі та обмежує тривалість ходу в межах 8–12 секунд.

\- \*\*`num\_ctx = 4096`\*\* та обмеження історії (системний промпт + останні 12 повідомлень): утримує модель і KV-кеш повністю у 8 ГБ відеопам'яті (RTX 5050 Laptop) без витіснення шарів у повільну оперативну пам'ять.

\- \*\*`reasoning\_effort = "none"`\*\*: вимикає прихований етап внутрішніх міркувань перед відповіддю, зменшуючи затримку до появи першого токена (`TTFT`) до \~2,2 с.
